# Sample Data

Three files support the book's empirical examples. All paths in the chapter
code are relative to the `code/` directory (`data/sample_loan_tape.csv`, ...).

| File | Grain | Rows | Used from |
| :--- | :--- | ---: | :--- |
| `sample_loan_tape.csv` | one row per loan (pool extract) | 135 | Ch. 12, 17, 18 |
| `sample_loan_panel.csv` | one row per loan (survival format) | 1,500 | Ch. 7, 9, 12, 13 |
| `sample_monthly_panel.csv` | one row per loan-month | 53,550 | Ch. 9, 10, 11, 13 |

## Provenance

`sample_loan_tape.csv` is an anonymized extract from a securitized pool of
Prime-indexed, government-guaranteed small-business loans. Row-level
characteristics (terms, spreads, fee stack, balances, sectors, states) are
genuine; all identifying attributes were removed — borrower names, loan
numbers, ZIP codes, cities, and lender names are dropped, origination dates
and balances are jittered, six-digit NAICS codes are coarsened to two-digit
sectors, and row order is shuffled. Terminal-status labels on zero-balance
rows are illustrative, since the source extract does not distinguish payoff
type.

`sample_loan_panel.csv` and `sample_monthly_panel.csv` are generated by
`make_sample_data.R`: loan characteristics are bootstrapped from the tape,
and monthly prepayment/default histories are simulated from seasoning,
refinance-incentive, sector, and vintage hazards. Coupons float on Prime
and the refinance incentive rises as Prime rises, so prepayments
accelerate in high-rate regimes — the variable-rate response documented
in Chapter 12. Hazard levels are calibrated
to the aggregate behavior of the public SBA 7(a) FOIA dataset (seasoning
ramp over 12-18 months, long-run CPR near 10%, lifetime defaults in the low
single digits, elevated 2008-2009 and 2020 vintages). The simulated
histories are synthetic; no borrower-level performance data is included.

Regenerate the panels with:

```bash
cd data && Rscript make_sample_data.R
```

## Column reference

**`sample_loan_tape.csv`** — `loan_id`, `pool_id`, `state`, `sector`
(two-digit NAICS), `sector_desc`, `orig_date`, `term_months`,
`maturity_date`, `accrual`, `rate_index`, `adj_frequency`, `base_rate`,
`loan_spread`, `coupon`, `strip_rate`, `guaranty_fee`, `fta_fee`,
`servicing_fee`, `net_rate`, `orig_balance`, `current_balance`, `seasoning`,
`remaining_term`, `status`, `reporting_date`. Rates are decimals; balances
are dollars; `coupon` is empty on paid-off rows.

**`sample_loan_panel.csv`** — one row per loan with the survival fields the
chapters use: observation time (`loan_age` = `time` = `age_months` =
`exit_age` = `end_age` = `end_month`), delayed-entry fields (`entry_age`,
`age_at_start`, relative to a 2015 study window), event indicators
(`prepay_event`/`prepay_flag`, `default_event`, `event`, `event_type` coded
0 = censored / 1 = prepay / 2 = default, `status`), and covariates
(`coupon`/`coupon_rate`, `balance`, `balance_log`, `orig_balance`, `sector`,
`sector_grp`, `state`, `state_unemp`, `year` = origination year,
`term_months`).

**`sample_monthly_panel.csv`** — one row per loan-month, January 2018
through November 2025: `loan_id`, `month`, `month_id`, `year`, `age`,
`coupon`, `prime`, `refi_incentive`, `macro_index`, `sector`, `state`,
`balance`, `balance_log`, `prepay_event`/`smm_event`, `event_type`
(`alive`/`prepay`/`default`), and a continuous `smm`/`log_smm` pair for the
panel-regression examples.
